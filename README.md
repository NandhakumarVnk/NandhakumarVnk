## About Me

I'm a final-year **Information Technology** engineering student at **Madras Institute of Technology**, focused on full-stack development with a strong interest in computer vision and applied ML. I like building complete, end-to-end products — from database schema to polished UI — and I'm currently deepening my skills in game development with Unity and Three.js on the side.

- 🔭 Currently building **Portfolio v1.0** — a React + TypeScript + Tailwind + Framer Motion personal site
- 🌱 Currently learning **Node.js internals, Unity/C#, Three.js, and Phaser.js**
- 💬 Ask me about **React, Spring Boot, OpenCV, or full-stack architecture**
- ⚡ Fun fact: I once built a fully animated birthday video from scratch using only HTML, CSS & JS
